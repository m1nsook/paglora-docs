# Themes and layouts

Paglora's website design system lets you choose **a page layout, a coordinated color palette, and an accent color separately**. All choices are stored locally in your project's `site.json` and used by the same renderer for Studio preview and static export.

## Choose a layout

Open **Design site → Theme** and select a website layout:

| Layout | Description |
| --- | --- |
| **Classic** | The original full-width documentation layout, with a header, sidebar, article and optional right-hand contents outline |
| **Inset** | A floating rounded header and a framed documentation body, with a softly shaded navigation panel |
| **Reading** | A quieter page with less visual chrome, more generous typography and article spacing |

These are **site layouts**, independent of each page's **Docs**, **Wide**, or **Landing** content layout. Existing projects remain on Classic unless you select something else.

## Choose a coordinated palette

Pick **Original**, **Graphite**, **Lavender**, or **Linen** under **Website color palette**. Each palette provides its own surfaces, text colors, borders and code-block colors for **light, dark and system-dark** appearances.

The **Website accent color** picker still controls links, keyboard focus, active navigation and accent highlights. Changing a palette does **not reset** your selected accent.

> [!TIP]
> This documentation project's source uses the **Inset** layout and **Graphite** palette, while keeping its existing blue accent. You can try different combinations in the editor's live preview before saving them.

## Preview, save, and export

1. Open **Design site → Theme**.
2. Choose a layout and palette. The **Live public website** pane immediately previews the design.
3. Switch between **Desktop**, **Tablet**, and **Mobile** to check responsive behavior.
4. Choose Light, Dark or System to inspect both appearances.
5. Press **Save layout**, then choose **Website → Build static site** when ready to publish.

The exported HTML records the selected layout and palette in safe attributes, and the first-party `styles.css` contains the matching rules. No extra JavaScript package or third-party runtime is needed.

Your `theme/custom.css` remains the last override. If a custom color or spacing rule conflicts with a preset, inspect that stylesheet before assuming the preset is broken.

## Compatibility and limits

Older `site.json` files without these settings default to **Classic** and **Original**. The settings do not alter the project manifest, Markdown, page visibility or navigation links.

The website is still generated by Paglora's Rust renderer and the preview intentionally disables site scripts. Appearance toggle/search interactions should be checked in a hosted HTML export over HTTP(S).
