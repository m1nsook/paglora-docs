# Components

Browse all currently supported, reusable Paglora Markdown components. Each entry has a **live preview**, **copyable Markdown source**, and a usage guide. The examples use Paglora's own documentation renderer, not React, MDX or a separate UI framework.

> [!NOTE]
> The catalog is inspired by the organization of component libraries. These components are authored as Markdown blocks in your own `docs/*.md` files; nothing needs to be installed.

## Layout

- [Cards](component-cards.md) — Reusable documentation cards for links and highlights.
- [Steps](component-steps.md) — A numbered timeline for step-by-step instructions.
- [Separators](component-dividers.md) — Separate sections with a theme-matched horizontal rule.

## Interactive

- [Tabs](component-tabs.md) — Switch between alternative instructions.
- [Disclosures](component-disclosures.md) — Expandable content with native browser behavior.

## Code

- [Code groups](component-code-groups.md) — Put several language examples into one tabbed group.
- [Code blocks](component-code-blocks.md) — Copyable code and terminal commands, displayed safely.

## Feedback

- [Callouts](component-callouts.md) — Note, Tip, Important, Warning and Caution messages.

## Data

- [Tables](component-tables.md) — Compare related properties using Markdown pipe tables.
- [Task lists](component-task-lists.md) — Read-only checked and unchecked task indicators.

## Media

- [Images](component-images.md) — Add bundled local PNG, JPEG, WebP or GIF assets.

## Content

- [Typography](component-typography.md) — Headings, emphasis, inline code, strike-through and quotations.
- [Lists](component-lists.md) — Standard ordered and unordered collections.
- [Links](component-links.md) — Navigation between public pages and safe external links.

## Scope

This gallery describes native Paglora documentation features, **not** installable shadcn React packages. Arbitrary JSX/TSX, custom browser scripts, advanced forms, and unimplemented widgets are not supported in published Markdown.
